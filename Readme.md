# Portal Halloween / Filmes e Séries de Terror
## Os objetivos desse projeto é criar um pequeno portal de filmes e séries de terror

## Tecnologias utilizadas: html, vs code, md, git bash, github e o .gitignore

## Estrutura do projeto
- Index.html
- Readme.md
- .gitignore
- series.html
- cadastro.html

## Como entrar no portal

Se vai entrar pelo o link que vou passar, depois de se vai se cadastrar(se tu quiser, não é um cadastro real e não guarda codigos) e clicar no inicio que já vai ter o botão explorar séries ou filmes em baixo, ou se clica no próprio botão séries para olhar as séries que se quer!

# As Branchs
## Main
Arquivo completo funcionando

## Develop
Área de desenvolvimento e base de origem para integrar as funcionalidades

## Feature/series
Desenvolvimento do Recurso Serie

## Feature/cadastro
Desenvolvimento do Recurso Cadastro

## Fix/correcao
Desenvolvimento para resolver o conflito


## Estratégia de Pull Requests

- Abra um Pull Request da feature/series para a develop.
- Abra outro Pull Request da feature/cadastro para a develop.
- Abra um Pull Request da develop para a main e conclua a integração.
